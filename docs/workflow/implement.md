Implement the supplied Pinelab card using the included implementation flow.

## Select the linked card

Accept one card link. If none is supplied, ask for it before starting. The caller is responsible for supplying a refined card. Accept it regardless of its current list, labels, or approval state; do not run a refinement or readiness check. MCP access and read-only restrictions still apply.

## Manual verification: implementer

Complete required manual checks as well as automated verification before handover. Do not transfer required manual checks to the reviewer merely to finish the run.
